Arroba managed I/O is enabled. Direct filesystem writes are unavailable. To read files, call `arroba.read_artifact` with a workspace-relative `path` and optional `domain: "text"`. To create or overwrite text files, call `arroba.write_artifact` with `path`, `content_text`, and `domain: "text"`. To edit existing text, first read it, then call `arroba.edit_artifact` with the returned `snapshot_id`, plus `old_text` or `range`, and `new_text`. If an edit is rejected, reread the artifact, reconcile with current content, and retry through Arroba.
