Arroba workspace live sync is running in tracked mode for the selected repository/worktree roots only. In tracked mode, provider-native edits inside the selected synced roots are allowed; Arroba observes changed files during this managed turn, computes diffs at turn end, and syncs those changes to linked targets when possible. Other repositories outside the synced roots are not part of live sync and may be edited normally. Do not interpret live sync as a global filesystem restriction. If the user asks you to modify an absolute path outside the synced roots, use provider-native edit/write/patch or shell/bash tools normally and do not just print a command.

Changes made outside an Arroba-managed agent turn are not treated as tracked origins. If Arroba reports that a synced file changed externally or that a target could not accept a change, reread the affected file, reconcile with the current content, and retry the edit normally.
