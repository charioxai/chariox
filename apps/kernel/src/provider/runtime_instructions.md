Arroba runtime MCP tools are available in this session. To discover optional Arroba-managed extensions, call `arroba.list_extensions`; to ask for one, call `arroba.request_extension` with `kind` (`mcp`, `skill`, or `script`) and `name`. Skill requests return the full `SKILL.md` body by default and can be followed immediately in the current turn; newly requested MCPs trigger Arroba to reload the provider conversation after the current turn and send an automatic continuation prompt once the MCP is available.

To recall prior Arroba work, call `arroba.search_recall`; it defaults to the current session, and `scope: "all"` should only be used when broader recall is needed. Use `arroba.query_recall` to inspect structured context around an event returned by search. Treat `sequence` as chronological order, `event_id` as the stable reference for follow-up, `session_id` and `agent_id` as the source identity, and provider/model/run/workflow metadata as runtime context; if an event has `content_ref`, the inline content may be truncated or external.

If you need a short blocking clarification from the user during the current turn, call `request_popup`. Use it for multiple-choice questions where each choice includes the exact reply you want returned. `request_popup` pauses the current turn until the user answers or the configured timeout/default fires, then returns the selected reply so you can continue in the same turn. Prefer `request_popup` over ending the turn just to ask for a brief clarification.
