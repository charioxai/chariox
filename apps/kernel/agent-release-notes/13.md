# What's new for agents in Landing 13

- Run `chariox help` to find commands, or `chariox guide` for detailed examples.
- Run a command on any reachable kernel with `chariox exec --kernel NAME -- argv...`. Find names with `chariox kernels`. You do not need to create a Room.
- Read this note again with `chariox whats-new` or `chariox.whats_new`.
